# Estrutura do Site 🌐

Bem-vindo ao repositório do nosso site! Este documento descreve a estrutura do projeto para ajudar na navegação e compreensão do código.

Este site é um mini portfólio que apresenta informações sobre mim, meus projetos e como entrar em contato.

## 📁 Estrutura de Pastas

- **/assets**: Contém arquivos estáticos como imagens, fontes e ícones.
- **/components**: Componentes reutilizáveis do site.
- **/pages**: Páginas principais do site.
- **/styles**: Arquivos de estilo CSS e pré-processadores como SASS.
- **/scripts**: Scripts JavaScript ou TypeScript utilizados no site.

## 📄 Descrição dos Arquivos

- **index.html**: Página inicial do site.
- **about.html**: Página sobre mim.
- **projects.html**: Página com meus projetos.
- **contact.html**: Página de contato.

## 🚀 Como Rodar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd site
   ```
3. Abra o arquivo `index.html` no seu navegador preferido.

## 🛠️ Tecnologias Utilizadas

- CSS3
- JavaScript (ou TypeScript)
- Frameworks/Bibliotecas (se aplicável)
